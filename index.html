Документация проекта

Процедурный ASCII-рендерер в браузере

ASCII Studio — компактный набор ES-модулей для генерации анимированной текстовой графики в реальном времени без Canvas API и WebGL. Все сцены строятся математически и выводятся в DOM-контейнер #ascii-canvas.

Ключевые возможности

Без зависимостей

Чистый нативный JavaScript (ES-модули) без сборщиков, фреймворков и сторонних движков.

Живая палитра и шифр

Меняйте символы на лету и применяйте шифры Цезаря, Виженера или двоичный код.

Процедурный рендер

Слои глубины, 3D-проекция сферы с материками и симуляция вихря с частицами обломков.

Быстрый старт

Подключите контейнер #ascii-canvas и модуль main.js в HTML-документе: 

<div id="ascii-canvas"></div>
<script type="module" src="./main.js"></script>

Поскольку используются ES-модули, открывайте страницу через локальный сервер (например, npx serve или Live Server).

Архитектура и API

Каждый модуль экспортирует стартовую функцию и получает объект состояния state вместе с функцией очистки clearAnimation: 

import { startAsciiEarth } from './ascii-earth.js';

const state = {
    getSpeed: () => 50,
    getAnimation: () => 'earth',
    setIntervalId: (id) => { intervalId = id; },
    getAsciiCanvas: () => document.getElementById('ascii-canvas'),
    getChars: (fallback, stripSpaces) => [...],
};

startAsciiEarth(state, clearAnimation);

Настройка и шифр

  • Шифр Цезаря: задайте текст в поле ввода и укажите сдвиг ползунком. Шифруются цифры, латиница и кириллица, результат отображается под панелью и сразу используется в текущей сцене.
  • Шифр Виженера: сдвиг символов на основе введённого ключевого слова.
  • Двоичный код: перевод текста в последовательность битов и обратно.
